GIT QUICK REFERENCE — EPFL ML COURSE
====================================

REMOTES AND BRANCHES
  origin    = your GitHub fork
  upstream  = EPFL's official repository
  main      = branch kept aligned with EPFL
  my-solutions = branch for your exercises

CHECK YOUR REPOSITORY
  git status                Show changed files and current branch.
  git branch                List local branches (* = current).
  git remote -v             Show remote repository addresses.
  git log --oneline -5      Show the five most recent commits.

WORK ON EXERCISES (my-solutions)
  git switch my-solutions   Move to your solutions branch.
  git add .                 Stage changes (check git status first).
  git commit -m "Message"   Save staged changes locally.
  git push                  Upload your commits to GitHub.

GET EPFL COURSE UPDATES
  git status                First check for uncommitted work; commit or stash it.
  git switch main           Switch to the course branch.
  git fetch upstream        Download EPFL updates, without changing files.
  git merge upstream/main   Integrate updates into local main.
  git push origin main      Update main on your GitHub fork.
  git switch my-solutions   Return to your working branch.
  git merge main            Bring the course updates into your solutions.
  git push                  Update your solutions branch on GitHub.

ONE-TIME SETUP (IF NOT ALREADY DONE)
  git clone https://github.com/epfml/ML_course.git
                             Download the official repository.
  git remote rename origin upstream
                             Rename the EPFL remote.
  git remote add origin https://github.com/YOUR_USERNAME/ML_course.git
                             Add your fork (replace YOUR_USERNAME).
  git switch -c my-solutions
                             Create and switch to the solutions branch.
  git push -u origin my-solutions
                             Publish it and set its tracking branch.

NOTES
  - Run these commands inside the ML_course folder.
  - If 'main' has a different name, substitute the actual default branch.
  - Merge conflicts can occur if both branches edit the same lines.
  - You cannot push to EPFL's repository without write permission.
